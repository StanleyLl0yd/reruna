# RERUNA Branding

## Canonical app icon

The project owner approved the following PNG as the canonical RERUNA app icon:

`assets/branding/reruna-icon.png`

Canonical SHA-256:

`5ecf527eb8a01550cce8949a66c3d68d77e716acdd12f2d887f09eee677f579b`

This exact PNG is the source of truth for project, repository, application, and future platform/store icon derivatives.

Do not overwrite, recompress, optimize, crop, pad, recolor, trace, redraw, vectorize, restyle, or otherwise rewrite the canonical file. Platform-required derivatives may only be raster derivatives that preserve the visible artwork.

The Android launcher resource at `app/src/main/res/mipmap-nodpi/ic_launcher.png` is intentionally byte-identical to the canonical source.

A 512×512 raster derivative is kept at `assets/branding/reruna-icon-512.png` for destinations that require that size. It is not the source of truth.

## Visual direction

The icon defines the project's visual direction:

- deep navy / near-black background;
- luminous cyan / electric-blue primary accents;
- violet / purple secondary accents;
- looping orbital geometry that communicates repetition, Reruns, Sync, and controlled temporal motion;
- minimal, high-contrast presentation;
- restrained glow rather than decorative clutter.

The current application palette already follows this direction. New project-facing visuals, repository artwork, screenshots, release graphics, and future application chrome should feel like the same product while preserving readability, accessibility, and platform conventions.

## Usage

Use the canonical icon itself for repository presentation where an original-quality source is appropriate, including the README.

For launcher, store, desktop, or other platform packaging, derive only the technically required raster sizes or raster container formats from the canonical PNG.

Do not create an SVG, Android VectorDrawable, SF Symbol, vector PDF, traced logo, or reconstructed approximation unless the project owner explicitly requests a new visual asset.
